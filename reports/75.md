# Issue #75 - 012 USDT Update Collector Binance Backfill

## What Changed

- Updated `01_pairUSDT/012_cryptoCollectorUsdt_Update.py` to use Binance-only OHLCV updates.
- Removed the CoinGecko fallback import and the CoinGecko fallback call path from the update collector.
- Changed empty-OHLCV coin handling:
  - Before: coins with no existing `ohlcv` rows were skipped.
  - After: coins with no existing `ohlcv` rows fetch full Binance daily history from the beginning.
- Kept the existing UTC current-day candle exclusion so unfinished daily candles are not saved.

## Why

New coins can exist in the `coins` table before they have any rows in `ohlcv`.
The old update script skipped those coins forever because it only knew how to update from an existing last date.

With this change, a newly added Binance USDT coin can be filled by the update script itself.
