## 무엇을 발견
- .chart-overlay-wrapper의 overflow: hidden이 lightweight-charts 캔버스 하단을 잘라냄
- BullBoxChart는 chart-overlay-wrapper를 사용하지 않아 해당 버그 무관

## 무엇을 수정
- Chart.css: .chart-overlay-wrapper { overflow: hidden → overflow: visible + flex 레이아웃 }
- Chart.css: .chart-area-fill { min-height: 0 → min-height: 400px + flex }

## 왜 그렇게 판단
- overflow: hidden이 차트 캔버스 하단 영역을 컨테이너 경계에서 잘라냄
- visible로 변경하면 캔버스가 컨테이너 밖으로 넘쳐도 표시 가능
- min-height 보장으로 차트 초기 높이 확보
