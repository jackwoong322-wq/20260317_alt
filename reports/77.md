## 012 Coverage Review

Current tests cover:

- `next_date()` date advancement.
- Early return when the `coins` table is empty.
- Skipping already up-to-date coins.
- Empty-OHLCV coin backfill path.
- Removal of the old `coingecko_fetch_daily_range` module attribute.

Coverage gaps found by the team:

- The empty-OHLCV backfill test should assert that Binance is called with `from_date=None`.
- Multi-coin empty-OHLCV backfill should be tested so all target coins are processed.
- Binance-only behavior should be checked through `fetch_binance_ohlcv_rows()` behavior, not only by checking that a CoinGecko symbol is absent.
- The boundary case where Binance returns only today's unfinished candle should verify that no save occurs.
- The test file has an unused `pandas` import.

## Recommendation

The current 012 unit tests are passing and adequate for a basic merge check, but the next test hardening pass should add direct assertions for:

- `from_date=None` full-history calls.
- Multiple empty-OHLCV coins.
- Empty Binance response behavior.
- Today-only candle exclusion.
