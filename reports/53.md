# #53 Vercel 배포 설정 - vercel.json 추가 보고서

## 문제
Vercel 빌드 시 `Command "cd 03_frontend && npm install" exited with 1` 오류

## 원인
Vercel 대시보드의 Install Command와 Root Directory 설정 충돌

## 해결
각 프론트엔드 디렉토리에 `vercel.json` 추가

### 03_frontend/vercel.json
- installCommand: npm install
- buildCommand: npm run build
- outputDirectory: dist

### 04_frontend_0222fb/vercel.json
- installCommand: npm install
- buildCommand: npm run build
- outputDirectory: dist

## Vercel 대시보드 설정
- Root Directory: `03_frontend` (또는 `04_frontend_0222fb`)
- Install Command: Vercel 대시보드에서 비워두기 (vercel.json이 제어)
- VITE_API_URL 환경변수 설정 필요

- PR 생성 및 main 머지
